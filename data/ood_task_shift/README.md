# OOD-TaskShift

OOD-TaskShift evaluates target-object substitution beyond the training task
distribution.

## Contents

- `tasks/`: 159 SafeBranch task configuration JSON files.
- `bddl/`: 159 matching BDDL problem definitions.
- `full_159.txt`: the complete generated evaluation set.
- `paper_eval_138.txt`: the common completed subset reported in the paper.

The package contains task metadata and BDDL definitions only. OmniGibson and
BEHAVIOR assets must be obtained separately under their own terms.
